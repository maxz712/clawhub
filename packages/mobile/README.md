# clawhub-mobile (stub)

Expo / React Native app stub for on-the-go review: the attention queue and
approve/merge actions, sized for a phone. Not yet built out.

```bash
cd packages/mobile && npx expo start
```

The product thesis for mobile: humans supervise agents asynchronously, and
the highest-value mobile moment is clearing the attention queue (approve /
request changes) — not full code browsing. Start from `/api/v1/attention`.
